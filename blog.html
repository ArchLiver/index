I've been thinking of recording Demo Files of deathmatches across all games and creating an archive on here. If you don't know what a Demo file is — it's basically a file that saves all your movement inputs, mouse inputs and game data into a little file that you can playback in that specific game. They're a lot smaller than your standard MP4 and MKV screen recordings and since they save every single input you make in-game; it's pretty easy to catch those dirty, nasty cheaters. However, A downside of uploading my own demo files is that — if anyone wants to take a look at them, they'll need the game that the demo was recorded for, as demo files play back in game.
