Description             : Recently, I've been playing a lot more
                          multiplayer with a mate, so, I thought I'd put
                          together a new episode for Doom that had Co-op
                          in mind. I've never included Co-op support in 
                          my WADs before, so I definitely did a lot more
                          thinking when it came to making these maps. 

                          All of these maps take inspiration from episode
                          1 & 2 of Doom. If you're playing Singleplayer,
                          I must warn you that Ultra Violence can be an
                          absolute pain. As I said before, Co-Op and
                          Deathmatch are supported  - so I recommend
                          getting a buddy if you can! 

                          This Episode takes around 30-45~ minutes to
                          complete, E1M1 - E1M8 are included only, so no
                          secret level. Each map took about a day to
                          make so I guess these count as speed-maps.

                          If you happen to find any bugs, let me know
                          immediately. Feedback is highly appreciated too!
